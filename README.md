# 论文与通用模型

本文件夹包含：

- `城市综合实力比较模型论文.docx`：学术论文，忽略全国城市排名与分档部分。
- `city_pair_model.m`：可适配任意两个城市的MATLAB通用模型。

## 使用方式

权重表与数据表需要保持统一字段：

权重表字段：

- 原表指标
- 规范指标
- 类别
- 实力类型
- 指标方向
- 重要性权重

数据表字段：

- 原表指标
- 规范指标
- 城市A值
- 城市B值
- 数据年份
- 数据来源
- 单位
- 是否更新

MATLAB调用示例：

```matlab
city_pair_model('权重表.csv', '数据表.csv', '城市A', '城市B', '输出前缀')
```

模型会输出综合实力总览、分类结果、文字摘要和分类图。
